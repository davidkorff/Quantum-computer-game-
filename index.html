How to Play

🎯 Goal: Transform qubits to match the target state


🔧 Controls:
1. Click a gate button to select it
2. Click a qubit to apply the gate


⭐ Stars: Fewer moves = more stars!


📖 Qubit States:

  • |0⟩ - Zero state (blue)
  • |1⟩ - One state (pink)
  • |+⟩ |-⟩ - Superposition (purple)

🔮 Gates:

  • X - Flips |0⟩↔|1⟩
  • H - Creates/removes superposition
  • Z - Flips phase |+⟩↔|-⟩
