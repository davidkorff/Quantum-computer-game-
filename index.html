Quantum Gate Reference

🎯 How to Play

Select a gate, then click qubit(s) to apply it. Transform qubits from initial to target state in minimum moves.

Single-Qubit Gates

X
Pauli-X (NOT)
Flips |0⟩↔|1⟩. Like classical NOT.
H
Hadamard
Creates superposition. |0⟩→|+⟩, |1⟩→|−⟩
Z
Pauli-Z (Phase)
Flips phase. |+⟩↔|−⟩. No effect on |0⟩,|1⟩
S
S Gate (√Z)
Quarter turn. |+⟩→|i⟩, |−⟩→|−i⟩
T
T Gate (π/8)
Eighth turn. Key for fault-tolerant QC.
Y
Pauli-Y
Combined X and Z with phase. |0⟩→i|1⟩

Two-Qubit Gates

CX
CNOT (Controlled-X)
Flips target if control is |1⟩. Creates entanglement.
CZ
Controlled-Z
Applies Z to target if control is |1⟩. Symmetric.
SW
SWAP
Exchanges two qubit states.

Qubit States

  • |0⟩ - Ground state (blue)
  • |1⟩ - Excited state (pink)
  • |+⟩ - Superposition (|0⟩+|1⟩)/√2
  • |−⟩ - Superposition (|0⟩−|1⟩)/√2
  • |Φ⁺⟩ - Bell state (entangled)
